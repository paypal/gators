Feature Selection
=================

* :func:`~gators.feature_selection.compute_iv` - Compute Information Value (IV) for features
* :func:`~gators.feature_selection.feature_stability_index` - Measure feature importance stability
* :class:`~gators.feature_selection.CorrelationSelector` - Select features by correlation threshold
* :class:`~gators.feature_selection.FeatureStabilitySelector` - Select features by stability score
* :class:`~gators.feature_selection.InformationValueSelector` - Select features by information value
* :class:`~gators.feature_selection.MutualInformationSelector` - Select features by mutual information
* :class:`~gators.feature_selection.PermutationImportanceSelector` - Select features by permutation importance
* :class:`~gators.feature_selection.PSIFilter` - Filter features by population stability index
* :func:`~gators.feature_selection.select_k_best_stable_features` - Select the top stable features
